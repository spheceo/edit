<h1 align="center">Edit</h1>

Edit is the team's video editor for macOS: scripts and edits in one app, with an AI agent that edits the project you're looking at, live.

## Install

1. Download `Edit-Apple-Silicon.dmg` from the [latest release](https://github.com/spheceo/edit/releases/latest), open it and drag Edit to Applications. Or, in Terminal:

   ```sh
   curl -fsSL https://raw.githubusercontent.com/spheceo/edit/main/install.sh | sh
   ```

2. Install [Claude Code](https://claude.com/claude-code) and sign in to it, and install Google Chrome.
3. Open Edit and sign in with your Google account (an admin adds you at [accounts.spheceo.com](https://accounts.spheceo.com)).

Edit updates itself. Developers: see [AGENTS.md](AGENTS.md).
