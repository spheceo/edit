# Commentary reference assets

`background.png` is the Internet Janitor wallpaper supplied with the team's Oct 19 style-research assets. It is imported on demand by `search_broll {queries:[]}` and stored with the project's cloud media. Other episodes' folder art and baked titles are deliberately not included.

The house guide names Akwe Pro Bold and links https://font.download/font/akwe-pro. The local review build uses `crates/edit-render/fonts/AkwePro-Bold.otf` from that download. Its download page lists **personal use**, unlike the renderer's OFL fonts; verify the team's commercial/distribution licence before shipping a public app release containing this font. This task creates an internal review video, not an app release.
