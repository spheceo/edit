# Codebase audit, Nov 1 2026

A full audit (8 parallel reviewers + an adversarial critic) of the server, web UI, e-code/timeline, agent text, security boundaries and streaming/lifecycle, followed by fixes for what the critic confirmed. Fixed on the way:

## Confirmed bugs, fixed

- **Linked-partner double shift** (`edit_plan.ts` update): selecting 2 of 3 clips in one link group moved the unselected partner twice (start 20, not 10). One shift per link now. Test: `three_linked_clips_move_their_partner_once…` in `test/edit_plan.test.ts`.
- **Id collisions across collections** (`edit_plan.ts` add): a clip could take a track/media/link/person id (`v1`), which native validate allowed. Rejected now, matching `Project::fresh_id`.
- **e-code times silently became 0** (`script_runtime.ts` `seconds`): `""`, `" "`, `":"`, `"1:"` and negatives parsed as 0/-5. They now throw `not a time`. Test in `test/script_runtime.test.ts`.
- **NTSC drift**: `insertTime` (`project.ts`), `dissolve` (`edit_plan.ts`) and the whole e-code read/describe path (`edit_script.ts`) used raw `settings.fps`; they now use the real ×1000/1001 rate.
- **Writer guides taught dead tools**: `agent/writer/*.md` (kept word for word) name Repack tools (`write_cut_ins`, `read_script`, …) that Script mode doesn't have; `plain()` was only applied to shape/length/sequence. The guides now go through `plain()` too (`writer/plan.ts`, `writer/revise.ts`, `extraGuides`), with PLAIN entries for the guides' own wordings. Test in `test/script_runtime.test.ts`.

## Permanent wedges (a hung dependency held everything), fixed

- `cloud_blocks.ts`: R2 block reads had no deadline — 6 hung reads stalled all cloud playback. 30 s timeout.
- `writer/cloud.ts`: sync fetches had no deadline and downloads no stall limit. Timeouts on the small calls, a 60 s no-data abort on downloads (not a total deadline, so slow big files still finish).
- `keychain.ts`: a hung `security` wedged sign-in; 15 s kill, and stdin EPIPE is no longer an uncaught exception.
- `uploads.ts` `run()` and `routes.ts` `ffmpegRun`: 2 min kill. `routes.ts` upload `receive` now cancels the body reader on idle timeout.
- `watch.ts`: `within` now aborts its loser (threaded into `askClaude` → `askPatiently`, and its ffmpeg dies too); `cutAt`'s ffmpeg has a 2 min kill instead of holding a CUTS slot forever.
- `mcp/index.ts`: finished long-tool flights for distinct keys leaked for the process's life; swept past `keepMs` on each call.
- `agent.ts` Codex reader: a newline-less stdout flood grew memory without bound; capped at 1 MB.

## Boundaries and error kinds, fixed

- `writer/commentary.ts` `getText` fetched any URL with redirects (SSRF to this Mac/LAN). It now goes through `net_guard.safeFetch`.
- Unguarded `JSON.parse`: WebSocket handler in web `lib/store.ts`, Chrome DevTools frames in `evidence_capture.ts`, and the e-code sandbox answer in `edit_script.ts` (which also now kills the sandbox if reading its output fails).
- Effect error kinds: `effect/service.ts` turned a stopped caller's abort into a retryable `ServiceUnreachable`; aborts now stay defects, so retries never re-ask a cancelled call. `effect/proc.ts` called every mid-run failure `ProcessNotStarted` ("ffmpeg is not available"); only starting is that now, the rest are `ProcessFailed`, and sub-minute timeouts no longer say "more than 0 min".
- `jobs.ts` resume logged `error.cause` ("undefined"); it logs the error itself now.
- Web stale writes: `writer/script-mode.tsx` accepted a slow `getScript` for a script since left; `writer/editor.tsx`'s poll wrote after unmount. Both re-check after the await (the critic refuted the cross-script variant — `key={opened.id}` remounts — so only the same-instance hole was real).

## Verified

Server typecheck, web typecheck, oxlint (0 errors), full server suite 1031 pass / 6 skip, web suite 234 pass. Rust untouched.

## Still open (needs a decision, not just code)

- **No auth on `/mcp`, `/api/ws` and mutating `/api/*` beyond loopback**: the server binds the Tailscale address by default, so any tailnet peer gets agent/project/export control (and unsandboxed e-code). Fix when wanted: a per-install bearer token when bound beyond loopback (`remote_support.ts`'s `requireLocalCli` is the pattern). Severity depends on who else is on the tailnet — the owner's call.
- **CI runs no checks**: `.github/workflows/` has only release builds; `just check` is enforced only locally via `publish`, and `nightly` tags without it.
- **Effect migration is infrastructure-deep, not wide**: 21 of ~230 server files; the rest still throw plain `Error` (1,473 sites) and spawn via `Bun.spawn` (34 files). The categories above (no deadline, race-without-cancel, unvalidated decode) are what to keep converting, module by module, rather than a big-bang rewrite.
- Not audited in depth: the Python export worker, Rust crates beyond edit-core spot checks, the relay body, and most web canvas/playback code.
